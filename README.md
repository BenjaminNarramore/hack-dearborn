# Worksheet Workshop

Printable, show-themed math worksheets for kids. Pick a grade level, a topic, a difficulty and up to three favorite shows, and get a PDF worksheet (with an optional answer key) plus a built-in Hint / Walkthrough helper.

Built for the [claude.ai](https://claude.ai) Artifacts runtime as a single self-contained HTML file.

> **Fan-made, educational project. Not affiliated with, sponsored by, or endorsed by the owners of any show, game, movie, book or toy named in it.** Names are used only to describe themes. No logos, artwork or scripts from those properties are included in this repository.

## Live demo

**Try it here:** https://claude.ai/artifact/6rhUuqv2DWCvWudgvZBAUt

The app runs inside claude.ai (it uses Claude to write the worksheets), so you'll need a free claude.ai account to generate worksheets. Generating a worksheet uses your own Claude usage. Opening `worksheet-workshop.html` directly from this repository shows the interface, but worksheet generation and PDF saving only work inside claude.ai.

## What it does

- **Numbered steps:** grade level (K-2, 3-5, 6-8), topic (about 25 topics grouped by area, plus "mix of a whole area"), difficulty (Warm-up, On level, Challenge, Varied), shows, optional notes, and number of problems.
- **Grade-aware topic list:** choosing a grade range narrows the topics to ones that fit it.
- **Show search:** a search box over a hand-built list of 301 kid-friendly shows, movie franchises, anime, games and book series, ranked by popularity, with type filters (TV, Movies, Anime, Games, Books, Toys).
- **Themed problems:** Claude writes the problems and answers, giving each problem exactly one of the chosen shows.
- **PDF export:** worksheet, worksheet only, or answer key only, built in the browser with [jsPDF](https://github.com/parallax/jsPDF).
- **Hint / Walkthrough chat:** tone adapts to a student (simple, encouraging) or a parent / teacher (concise, with tips for explaining it).
- **Cozy classroom design:** light and dark themes, works at phone width.

## How it runs

The page uses the Artifacts runtime capabilities `sample` (ask Claude) and `downloads` (save a file). Publish `worksheet-workshop.html` (or the built file in `dist/`) as a claude.ai Artifact and declare both capabilities.

Opened anywhere else (for example by double-clicking the file), the interface loads and the show search and preview work, but worksheet generation and saving are disabled because `window.claude` is not available.

## Project files

| File | Purpose |
|---|---|
| `worksheet-workshop.html` | The whole app (HTML, CSS, JS). |
| `shows-database.js` | The show list: name, type, popularity estimate, color, search aliases, and a short "world" description Claude uses to theme problems. |
| `build.ps1` | Builds `dist/worksheet-workshop.html`: refreshes the show list from `shows-database.js` and, if present, embeds local poster thumbnails. |
| `tools/fetch-posters.ps1` | Optional. Creates `show-posters.js` locally (see below). |
| `.gitignore` | Keeps posters, build output and secrets out of git. |

## Editing the show list

Edit `shows-database.js` (one `S(...)` line per show), then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Popularity values are rough estimates, and the "world" text is written from general knowledge, so spot-check any entry you rely on.

## Posters (optional, local only)

The repository does **not** include poster images. Without them, each show card uses a colored tile with the show's initials.

Posters are studio artwork delivered through [TMDB](https://www.themoviedb.org). To add them on your own machine:

1. Create a free TMDB account and copy your API Key (themoviedb.org/settings/api).
2. Run:

```powershell
$env:TMDB_KEY = "your-tmdb-api-key"
powershell -ExecutionPolicy Bypass -File .\tools\fetch-posters.ps1
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

This writes `show-posters.js` (ignored by git) and embeds it into `dist/worksheet-workshop.html`.

Please follow TMDB's API terms: personal / non-commercial use unless you have a written agreement with them, show their logo and the notice below, and do not cache TMDB data for more than 6 months. Do not commit `show-posters.js`.

> This product uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.

## Good to know

- Worksheet problems and answers are generated by an AI model. Math answers can occasionally be wrong, so check the answer key before handing a worksheet to a student.
- Generation uses the viewer's own Claude usage inside claude.ai.
- Third-party resources loaded at runtime: jsPDF (cdnjs) and Google Fonts (Fredoka, Nunito, Caveat).
